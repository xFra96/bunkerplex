Installa BunkerPlex sulla TV

Come si accende il debug sulla TV (una volta sola)
  1. Google TV / Android TV: Impostazioni → Sistema → Info → premi 7 volte su Build del sistema operativo Android TV (compare «Ora sei uno sviluppatore»).
  2. Torna in Impostazioni → Sistema → Opzioni sviluppatore e attiva Debug USB (se c'è, anche Debug di rete o ADB in rete).
  3. Fire TV: Impostazioni → La mia Fire TV → Informazioni → premi 7 volte sul nome del dispositivo, poi Opzioni sviluppatore → Debug ADB attivo.
  4. Porta la TV sulla schermata Home, telefono e TV sullo stesso Wi-Fi, poi premi Cerca le TV.

Le TV che hanno solo Debug wireless con codice di associazione non sono ancora supportate dal telefono: lì usa «Installa sulla TV dal PC» nel server BunkerPlex.
